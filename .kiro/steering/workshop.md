# Workshop project rules

- Use HTML, CSS, and vanilla JavaScript only.
- Add no dependencies, backend services, or external requests.
- Reuse the existing cards, controls, and visual style.
- Change only code relevant to the current mission.
- Do not implement later missions or unrelated enhancements.
- Use text labels as well as visual status indicators.
- Keep logic readable for beginner programmers.
- Summarize changes and provide short manual verification steps.
